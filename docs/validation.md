# 表示と操作の検証

対象は現在の表面・裏面・CSSです。Ankiのフィールドと条件付き表示をサンプル内容で展開し、Chromium 151で表示しています。

## 参考版との一致

最後に添付された `表面1.txt`・`裏面1.txt`・`CSS.txt` を参照しました。参考HTMLからレベル・出典・例文2〜6だけを外し、同じ6フィールドで比較しています。

参考CSSの2822バイトが現在のCSSの先頭と完全に一致することを確認しました。参照CSSのSHA-256は `75575fbb2189fb0d998b56158758f6c231fd162cb678c516b8d2834b1d59ef81` です。

320・390・1024pxの3種類の幅、ライト／ダーク、表面／裏面の合計12条件で、参考版と現在の版を同じブラウザ内に表示しました。以下を比較しています。

- 問題、答え、上下の横線、単語情報、例文、日本語訳の各領域。
- 書体、文字サイズ、太さ、文字間隔、行間、色、揃え方。
- 上下の余白、内側の余白、横線の太さと色、背景色。
- 各領域の位置・幅・高さ。許容誤差は0.5pxです。

12条件すべてで一致しました。比較に使った問題は `serendipity`、答えは日本語の段落2つ、例文と日本語訳はREADMEの表示見本と同じ内容です。

## 表面から裏面への伸縮

表面の問題領域を保持したまま答えを追加し、その領域の高さが増えることを確認しました。以下は問題が `apple` の場合の実測値です。

| 画面幅 | 問題だけ | 短い答えを表示 | 長い答えを表示 |
| --- | ---: | ---: | ---: |
| 320px | 145px | 180px | 1763px |
| 390px | 145px | 180px | 1518px |
| 480px | 145px | 180px | 1273px |
| 768px | 145px | 180px | 1098px |
| 1024px | 145px | 180px | 1098px |

短い答えは「りんご」、長い答えは段落2つと箇条書きのサンプルです。短い答えでも35px広がり、下の横線と単語情報が下へ移動します。高さの最低値は0px、上限はありません。

## その他の確認

- 既存6フィールドだけを使い、色切替・保存処理がないこと。
- 表面のスクリプトを実行しない場合でも裏面が表示されること。
- 引用符、バックスラッシュ、段落、箇条書き、HTMLの改行。
- 空文字・空の改行タグ・ゼロ幅文字だけの答えで、答えの本文が追加されないこと。
- 例文・日本語訳が空の場合の条件付き表示。
- 長い連続文字列の折り返しと、画面全体に横スクロールが出ないこと。
- 後から画像を読み込むと問題・答えの領域がさらに広がること。
- 幅広の表の横スクロール、200%拡大、844×390pxの横向き。
- 保存領域が使えない場合と、旧テーマのクラスが残っている場合。
- OSのダークモード、AnkiのnightMode / night_modeクラス。

JavaScriptエラーは発生していません。テンプレート3ファイルと展開済みHTMLのImpeccableによる検査でも、指摘はありませんでした。
