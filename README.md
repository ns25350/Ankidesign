# Ankiカードデザイン

元の4色の切替、丸い単語カード、ノート風の罫線を保ち、答えの量に合わせてカードの高さが増えるテンプレートです。

## Ankiへの反映

1. Ankiのブラウザで対象のノートを選び、「カード…」を開きます。
2. 現在の「表面のテンプレート」「裏面のテンプレート」「スタイル」の内容を控えておきます。
3. 以下のファイルの**内容全体**を、それぞれの欄に貼り付けて置き換えます。CSSも追記ではなく置き換えます。

| ファイル | 貼り付け先 |
| --- | --- |
| [templates/表面.txt](templates/表面.txt) | 表面のテンプレート |
| [templates/裏面.txt](templates/裏面.txt) | 裏面のテンプレート |
| [templates/CSS.txt](templates/CSS.txt) | スタイル |

4. 短い答えと長い答えのカードをプレビューし、答えが最後まで表示されることを確認して保存します。

既存のフィールド名 `表面`、`裏面`、`単語番号`、`品詞`、`例文1`、`日本語訳1` をそのまま使います。新しいフィールドの追加は不要です。

## GitHubで確認・編集

`templates` フォルダの3ファイルを開くと、そのまま内容を確認・コピーできます。ダウンロードは不要です。

GitHub上で変更する場合は、対象ファイルを開いて鉛筆アイコン（Edit this file）から編集し、保存します。リポジトリを編集しただけではAnkiへ自動反映されないため、変更後の内容をAnkiの対応する欄にも貼り付けてください。

## 表示の動作

- 白いカードの幅は元と同じ最大500pxです。高さは本文と画像に合わせて自動で増え、長いカードは画面全体を縦にスクロールして読めます。
- 40文字以内の答えは元の24px・太字・中央表示を使います。それを超える答えは20px・左揃えにし、1.6倍の行間で表示します。文字を際限なく小さくする処理や、高さを測って固定する処理はありません。
- 表面の単語は元と同じ文字数の基準でサイズを調整します。
- フィールドのHTML、段落、箇条書き、`<br>`による改行を保ちます。HTMLでは、生の改行だけでは改行表示されないため、改行はAnkiのフィールドエディタで入力してください。
- 画像はカード内に収まる幅で表示します。幅の広い表は、表の中だけを横にスクロールできます。
- 例文1が空なら例文のノート枠を表示しません。日本語訳1が空なら訳の行を表示しません。
- 色の切替は表面・裏面の両方で使えます。保存が許可されている環境では、従来と同じキー `anki-custom-theme` で選択色を記憶します。保存が利用できなくても、答えの表示とその画面での色の切替は動きます。
- OSのダークモードと、Ankiの `nightMode` / `night_mode` クラスに対応しています。

## 修正点と検証

元のCSSにも固定の高さ指定はありませんでした。長い内容を読みやすくするために、行間・折り返し・段落の余白を指定し、カードとノート枠の高さを内容に合わせるように整えています。

また、元の裏面の `slot.innerHTML = "{{裏面}}";` は、フィールドに引用符や改行があるとJavaScriptの構文が壊れる場合がありました。修正版ではフィールドをHTMLとして受け取り、要素を答えの場所へ移動するため、その問題を避けられます。裏面でも色と表面の文字サイズを初期化するので、`FrontSide` 内のスクリプトが裏面で実行されない場合にも対応します。

Chromiumで以下を確認しています。

- 320・390・768・1024px幅で、短い答えと長い答えを表示。長い答えでカードの高さが増え、本文の切り捨てや下のノート枠との重なりがないこと。
- 段落、箇条書き、引用符、バックスラッシュ、長い連続文字列、空の答え、空の例文・訳。
- 後から読み込まれる画像に合わせた高さの変化と、幅の広い表のスクロール。
- 表面から裏面への色の保持、裏面での色の切替、保存が利用できない場合の動作。
- OSとAnkiクラスによるダークモード。JavaScriptエラーがないこと。

Anki本体・AnkiMobile・AnkiDroidでの実機確認はこの環境では行っていません。3つの欄を差し替えた後、利用中のAnkiのプレビューでも確認してください。
