# Ankiカードデザイン

添付の参考版のデザインをそのまま使い、現在の6フィールドに合わせたテンプレートです。白地と紺の文字、問題の上下の横線、中央揃えの単語情報を再現しています。**答えを表示すると、問題と答えの領域が内容の分だけ下へ広がります。**

## Ankiへの反映

次の3ファイルを開き、内容全体をAnkiの「カード…」に貼り付けてください。**表面・裏面・スタイルの3つを、既存の内容ごと置き換えます。** CSSへの追記では以前の指定が残るため、スタイルも丸ごと差し替えてください。

| ファイル | 貼り付け先 |
| --- | --- |
| [templates/表面.txt](templates/表面.txt) | 表面のテンプレート |
| [templates/裏面.txt](templates/裏面.txt) | 裏面のテンプレート |
| [templates/CSS.txt](templates/CSS.txt) | スタイル |

フィールドは `表面`、`裏面`、`単語番号`、`品詞`、`例文1`、`日本語訳1` です。追加は不要です。参考にあるレベル・出典・例文2〜6は使いません。

差し替える前に元の内容を控え、差し替え後に短い答えと長い答えをプレビューしてください。リポジトリの変更はAnkiに自動反映されません。

## 表示の動作

- 参考CSSの配色・文字サイズ・文字間隔・余白・横線をそのまま使っています。
- 問題と答えを中央に表示し、答えの量に応じて領域が広がります。参考と同じく長い問題だけ左揃えになります。
- No.と品詞はラベルが上、値が下の配置です。例文と日本語訳は裏面だけに表示します。
- 色切替のボタンや保存処理はありません。参考と同じライト／ダーク表示を使います。
- 答えの引用符、段落、箇条書き、HTMLの改行をそのまま表示できます。
- 長い連続文字列は折り返し、画像は領域の幅に収めます。幅広の表は表の中を横スクロールできます。
- 外部フォントやWebライブラリの読み込みは不要です。

## 検証と編集

参考版も同じ6フィールドに絞り、同じ内容を入れて比較しました。320・390・1024px幅、ライト／ダーク、表面／裏面の12条件で、文字・余白・色と各領域の位置・大きさが一致しています。[検証結果](docs/validation.md)

Anki本体・AnkiMobile・AnkiDroidでの実機確認は未実施です。利用中のAnkiのプレビューでも確認してください。
